🛍️ Shopping Behavior Analysis | Data Analytics Project

📌 Project Overview

This project focuses on analyzing customer shopping behavior to identify purchasing patterns, revenue trends, and customer preferences. The analysis was performed using Python, SQL, and Power BI to transform raw data into meaningful business insights.

🛠️ Tools & Technologies

- Python: Data loading, Exploratory Data Analysis (EDA), and data cleaning.
- Pandas & NumPy: Data manipulation and preprocessing.
- MySQL Workbench: SQL queries, data analysis, and business insights.
- Power BI: Interactive dashboard development and data visualization.

🔍 Project Workflow

1. Data Loading & Exploration (Python)

- Imported the dataset using Pandas.
- Explored the dataset structure, columns, and data types.
- Performed Exploratory Data Analysis (EDA).
- Identified missing values, duplicates, and inconsistencies.

2. Data Cleaning (Python)

- Handled missing and duplicate values.
- Checked and corrected data types.
- Prepared the dataset for further analysis.

3. SQL Analysis (MySQL)

- Analyzed customer purchasing behavior.
- Calculated total revenue and purchase trends.
- Performed customer segmentation based on age groups.
- Analyzed revenue contribution by age group.
- Explored customer subscription and purchasing patterns.
- Used aggregate functions, CASE statements, GROUP BY, and subqueries to generate insights.

4. Dashboard Development (Power BI)

- Connected and imported the cleaned dataset.
- Created interactive visualizations and reports.
- Developed charts to analyze customer demographics and purchasing behavior.
- Visualized revenue trends, age-group contributions, and subscription patterns.
- Designed an interactive dashboard to present key business insights.

📊 Key Business Areas Analyzed

- Customer purchasing behavior
- Revenue distribution by age group
- Gender-based shopping patterns
- Customer subscription analysis
- Product category performance
- Customer spending trends

🎯 Project Objective

The main objective was to demonstrate an end-to-end data analytics workflow, from raw data exploration and cleaning to SQL-based analysis and interactive Power BI reporting.
